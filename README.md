# 프롬프트 관리 프로그램

Python 콘솔 기반으로 동작하는 나만의 프롬프트 관리 프로그램입니다.
프롬프트를 등록, 조회, 검색하고 즐겨찾기로 관리할 수 있습니다.
(프로그램 실행 중에만 데이터가 유지되며, 종료하면 초기화됩니다.)

## 실행 방법

1. 이 저장소를 clone 하거나 다운로드합니다.
2. 터미널(또는 VSCode 터미널)에서 프로젝트 폴더로 이동합니다.
3. 아래 명령어로 실행합니다.

```bash
python prompt_manager.py
```

## 기능 목록

1. 프롬프트 추가 — 제목, 내용, 카테고리를 입력해 새 프롬프트를 등록합니다.
2. 프롬프트 목록 — 등록된 모든 프롬프트를 확인합니다.
3. 카테고리별 조회 — 원하는 카테고리의 프롬프트만 모아서 봅니다.
4. 프롬프트 검색 — 제목/내용에 포함된 키워드로 검색합니다.
5. 프롬프트 상세 보기 — 프롬프트 하나를 선택해 전체 내용을 확인합니다.
6. 즐겨찾기 관리 — 프롬프트를 즐겨찾기에 추가하거나 해제합니다.
7. 즐겨찾기 목록 — 즐겨찾기한 프롬프트만 모아서 봅니다.
0. 종료 — 프로그램을 종료합니다.
